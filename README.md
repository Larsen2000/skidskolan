# Skidskolan på berget

Ett pekspel för iPad där barn övar franska inför skidskolan i La Plagne och Les Arcs. Skidläraren Camille pratar franska och murmeldjuret Mimi förklarar på svenska.

Spelet är en webbapp som fungerar offline. Öppna sidan i Safari, välj Dela → Lägg till på hemskärmen och öppna det en gång med internet. Efter det fungerar det utan uppkoppling.
